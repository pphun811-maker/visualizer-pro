# Visualizer Pro

Windows 本地音频分析和可视化软件，用于主屏全屏观察。四组仪表同步运行；按 Tab 隐藏参数。界面使用黑灰色，信号图形可选经典蓝、柔和多彩或标准多彩。

## 直接运行

从源码克隆后，请先按下方“开发”说明构建便携包；仓库不包含构建产物和测试数据。

打开 `artifacts/VisualizerPro-win-x64/VisualizerPro.exe`。发布包包含 .NET 运行时和 FFmpeg，无需安装 Python、.NET 或额外解码器。将整个目录一起移动；不要只复制 exe。

- 默认使用 20 ms WASAPI 缓冲监听 Windows 当前播放设备，可在顶部选择其他输出设备。
- 点击“打开文件”或拖入 WAV、FLAC、MP3、AAC/M4A、OGG 等音频文件。文件模式直接分析解码音频，播放音量不影响仪表。
- 不需要麦克风，不连接网络，不上传音频。
- 系统采集遵循 Windows WASAPI 能捕获的内容，受保护的音频可能无法采集。

分区边界可拖动。参考快照最多四张，可隐藏、删除、导入和导出。“更多”菜单提供保存参考、PNG 截图、频谱 CSV 和参考 JSON 导入/导出；CSV 是分析数据，不包含显示斜率。

数字切换键同时支持主键盘和数字小键盘。也可以使用顶部三个模式下拉框；快捷键和下拉框始终同步，选择会保存。双击仪表放大，按 Esc 还原；按 Tab 隐藏顶部参数区后仍可操作。输入参数数字或展开下拉菜单时，数字键不会切换面板。电平与响度只有一种视图。

顶部保留布局、仪表模式和配色选择。“分析参数”和“显示设置”按需展开，同一时刻只展开一组；声道、平均、衰减、历史长度与频谱参数在“分析参数”内。

“配色 → 柔和多彩”按固定频段使用灰蓝（20–120 Hz）、青灰（120–500 Hz）、鼠尾草绿（500 Hz–2 kHz）、沙金（2–6 kHz）、灰紫（6–20 kHz）。FFT、1/3 倍频程、二维声谱、三维瀑布和分频段声场共用对应关系；FFT 在频段边界附近柔和过渡。二维/三维声谱的明暗仍表示电平，颜色表示频段，缩放不会重新分配颜色。L/R 波形、整体声场和电平继续使用蓝色，避免把声道或音量误作频率。配色选择会保存；原配置默认沿用经典蓝，切换不改变冻结数据、回看位置或测量读数。

“标准多彩”使用更清晰的蓝、青、绿、橙、紫，对应相同五个频段；提高正常色彩的辨识度，同时保持中等饱和度。原“柔和多彩”配色保持不变；升级后已有选择继续保留。频谱内图例与仪表同步切换，三种选项均会保存；顶部不再显示频段图例。

“声谱色 → 强度热力”仅为时间声谱和三维瀑布启用按电平着色的模式，渐变直接采自用户参考图片：暗绿/青、蓝紫、粉色、米黄到白色；不附加颜色标尺。同等电平跨频率使用同色，固定使用参考图的 −130～0 dBFS 映射，显示斜率不改变强度颜色；“声谱范围”仍控制跟随配色的颜色范围及三维高度范围。切换会重着色冻结历史并保存选择，其他仪表仍使用“配色”选项。选择“跟随配色”恢复原声谱配色。

强度声谱使用独立的 2048 列瞬时数据，不复用 FFT 曲线的平均、频率平滑或衰减。48 kHz 下低频采用 32768 点、高频采用 8192 点 Hann 窗，200～400 Hz 交叉过渡；其他采样率相应处理。高采样率先低通抽取，20 kHz 以上保留原采样率 FFT 的频带峰值。二维先按屏幕物理像素重采样能量，再着色，不对颜色做二次模糊。分析窗预热完成后显示对应频段，避免启动时的横向伪亮条。冻结探针与三维强度模式读取这份瞬时谱，因此可能与使用不同分析窗、带平滑和衰减的 FFT 曲线读数不同。

主窗口使用黑灰自绘标题栏，右上角提供最小化、最大化/还原和关闭。窗口模式下可拖动顶部空白或 Logo，双击切换最大化；F11 仍切换全屏。

窗口菜单提供置顶、托盘、测量重置、缓存清理和读数说明。关闭按钮会退出；收起到托盘后双击图标恢复。

拖动或调整整个窗口时，仪表保留上一帧，松开后恢复实时显示；音频与后台分析继续运行。

频谱游标使用独立叠加层，冻结画面时仍可移动查看。FFT 电平按对数频率轴在相邻谱点间插值，表示当前曲线的 dBFS；倍频程探针显示所在频带的中心、边界和 dBFS RMS。显示斜率不加到读数上。拖动参数时合并分析更新，松开后提交最终值；鼠标操作期间降低仪表重绘频率，停止操作后恢复正常刷新。

时间声谱保存最近 10 / 30 / 60 秒的分析快照，时间分辨率约 50 ms。鼠标悬停可在图内读取相对时间、Hz 和 dBFS；点击或拖动选择时刻后，频谱、电平、声场或波形同步到该时刻。冻结时当前历史窗口保持不动，后台继续收集；恢复实时会补上历史，超出所选保存时长的数据正常淘汰。音频块间隔稍大于 50 ms 时使用邻近快照，较长中断留空。时间声谱上 Shift 拖动仍用于频率缩放。回看不会改变音频播放位置，也不提供历史音频回放。

展开“显示设置”可选择当前默认、平稳或灵敏响应，也可以单独调整频谱上升时间、声场灵敏度和余辉长度，以及 5 / 10 / 20 / 30 ms 的波形窗口。当前默认保持首轮确认的 35 ms 上升、1× 灵敏度、100 ms 余辉；衰减为 0 时频谱仍即时响应。显示设置与分析参数分别保存，不改变 RMS、响度或真峰值。

三维瀑布使用同一份频谱历史，横轴为对数频率，纵深为相对时间，高度和颜色明暗表示电平。显示设置可选择 4 / 8 / 16 秒可见窗口（不超过历史保存时长）。点击或拖动曲面回看，滑块可访问更早的数据，曲面窗口自动跟随所选时刻；Alt 拖动调整视角，滚轮缩放频率，双击放大面板。曲面探针读取可见三角面的插值，选择时刻后其他仪表使用最近的实际分析帧。绘制时按频率列保留峰值以免漏掉窄带脊线；二维声谱仍可随时切回。

## 读数与参数

- **频谱**：窗函数相干增益校正的 dBFS 峰值幅度；Stereo 使用左右声道功率平均，因此反相信号仍可见。L/R 分别叠加显示，Mid=(L+R)/2，Side=(L-R)/2。每个对数频段显示其中最大的 FFT 谱线；低于 FFT 分辨率的频率格会共享谱线。
- **1/3 倍频程**：20 Hz–20 kHz 的 31 个优选中心频带，按十进制精确边界汇总 FFT 能量，边界谱线按覆盖比例分配，窗函数能量归一化后以 dBFS RMS 显示；最高频带受 Nyquist 限制。0.5 峰值的正弦信号约为 −9.03 dBFS RMS，与 FFT 峰值幅度的 −6.02 dBFS 不同。频率平滑不影响频带能量，时间平均、上升/衰减、峰值保持和声道选择仍有效。淡色柱和探针约等号表示 FFT 分辨率不足，可增大 FFT；这不是 IEC 61260 标准滤波器组或声压计。CSV 随当前模式导出，倍频程包含边界和 RMS 单位。新参考快照保存两种数据；旧 FFT 快照可继续导入，但在倍频程模式下不显示参考线。
- **平滑与平均**：频率平滑和时间平均在功率域计算。显示斜率以 1 kHz 为参考。它们不改变原始电平或响度；频率平滑会降低窄带音调的显示峰值。
- **电平**：400 ms RMS；Peak 是约 350 ms 时间常数的衰减包络。True Peak 是本次测量的最大真峰值，使用 4 倍、每相 48 tap 的窗化 sinc 重建。
- **响度**：立体声 BS.1770 K 加权。M=400 ms，S=3 s，I=400 ms/100 ms 重叠块，-70 LUFS 绝对门限和 -10 LU 相对门限。积分使用 0.01 LU 固定直方图以限制内存。没有足够数据时显示“—”。
- **声场**：M 纵轴、S 横轴，显示自动增益；相关度使用最近 400 ms 数据。静音时相关度未定义，显示“—”。
- **分频段声场**：20–120、120–500、500–2000、2000–6000、6000–20000 Hz 五段（上限不超过 Nyquist），显示窗函数加权 FFT 的相关度及侧声道能量占比，使用约 200 ms 平滑。S 占比为 S 能量 / (M 能量 + S 能量)：同相居中信号约 0%，反相信号约 100%，不是传统混音“宽度旋钮”的百分比；无有效信号时显示“—”。
- **波形示波器**：L/R 共用左声道上升零点触发，固定 ±1 FS 幅度刻度；稀疏采样直接连线，密集采样用每列最小/最大值保留瞬态。回看时显示所选快照内的短时波形。它不是 True Peak 重建曲线。
- **多声道**：实时输入按 Windows 标准 FL/FR/FC/LFE/BL/BR/SL/SR 顺序降混为立体声，中心与环绕系数 0.707，不计 LFE；文件降混由 FFmpeg 完成。当前测量反映降混后的立体声，不是多声道广播响度。
- **历史与重置**：切源、定位和循环跳转重置本次测量与实时声谱。暂停文件不会积入静音。整曲分析结果与本次播放测量分别显示。
- **文件同步**：根据 WASAPI 实际输出时钟选择对应的分析帧，避免用解码器预读位置驱动仪表。整曲概览使用 4096 点 FFT，最多 2400 列，响度轨迹为瞬时响度。

这是观察和辅助分析工具。实现已用合成信号与 FFmpeg EBU R128 交叉验证，未经过第三方计量认证。

## 本机数据

设置、参考快照与日志：`%LOCALAPPDATA%\VisualizerPro`。整曲概览缓存上限 512 MB，可以从菜单清理。缓存保存分析结果，不保存解码 PCM。可用 `VISUALIZERPRO_DATA_DIR` 环境变量为测试指定独立数据目录。

## 开发

需要 Windows 10 2004 或更新版本、.NET 10 SDK、PowerShell，首次构建需要网络下载 NuGet 依赖和 FFmpeg。

```powershell
dotnet restore src/VisualizerPro.App/VisualizerPro.App.csproj --configfile NuGet.Config
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Get-FFmpeg.ps1
dotnet run --project src/VisualizerPro.App --no-restore

pwsh -File scripts/Test.ps1 -Reference -Desktop
pwsh -File scripts/Publish.ps1
```

核心分析位于 `src/VisualizerPro.Core`，不依赖 WPF 或音频设备。桌面程序集负责 WASAPI、FFmpeg、绘图和交互。仪表优先使用 Skia OpenGL 加速，以 60 FPS 为流畅度目标；实际刷新受显示器和硬件影响。每个上下文 GPU 资源缓存上限 32 MiB；初始化失败时回退到软件绘制。也可以设置 `VISUALIZERPRO_SOFTWARE=1` 强制兼容模式。采集/播放、分析工作线程、整曲任务和 UI 绘制分离；实时队列 32 块、播放同步历史 64 帧，回看缓冲最多 1200 个分析快照（冻结时另持有一个窗口的引用），均有界。快照包含短时波形，内存占用随采样率增加，不会保存完整音频文件到磁盘。截图用相同绘图逻辑在 CPU 表面重新渲染，避免显卡驱动对 GPU 图像读回的兼容差异。

`--demo` 使用明确标注的合成测试信号，不采集真实声音。`--smoke-test <png路径>` 自动生成界面截图并退出；`--integration-test <报告目录>` 运行静音的桌面集成检查；`--open <音频路径>` 启动后打开文件。

`pwsh -File scripts/Test-Responsiveness.ps1` 检查启动全屏的原生像素边界、窗口移动和恢复后的帧间隔。设备枚举在单独的后台任务中运行，界面读取最新设备快照。本地工作区另有 `HANDOFF.md` 记录实现和交接，该文件不随公开源码发布。

`--input-test <报告目录>` 检查 WPF 坐标映射、冻结游标和路由式滑块拖动，不注入真实鼠标。加 `--native-input` 可在具备交互桌面的环境中检查系统鼠标输入；该模式会移动鼠标，结束后恢复位置并关闭窗口。当前运行环境的系统鼠标事件未能送入 WPF，因此本次只完成默认模式检查。

`pwsh -File scripts/Test-Exploration.ps1` 运行历史回看、恢复实时、显示设置持久化、新仪表和放大布局检查；使用隔离配置并自动关闭窗口。对应应用参数为 `--exploration-test <报告目录>`。

`pwsh -File scripts/Test-SpectralModes.ps1` 检查快捷键、倍频程读数/快照/CSV、三维曲面投影与拾取、历史回看、相机设置和实时刷新，以及频段配色的实际 RGB、缩放/冻结/历史/持久化与 1120×740 布局；对应参数为 `--spectral-test <报告目录>`。可用 `VISUALIZERPRO_SOFTWARE=1` 对相同功能检查软件绘制回退。
